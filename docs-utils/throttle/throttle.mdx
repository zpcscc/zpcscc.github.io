---
title: "throttle"
---

## 描述

节流函数

## 参数

| 参数名 | 类型                  | 描述                  |
| ------ | --------------------- | --------------------- |
| func   | `function` | 需要节流的函数 |
| limit  | `number`   | 节流等待的时间 |

## 返回

`function` - 返回节流后的函数

## 示例 _(ts类型)_

```typescript
throttle(func: AnyFunction, limit: number): AnyFunction
```

## 示例 _(demo)_

```typescript
import { throttle } from '@site/src/utils';

const test = () => {
  console.log('执行一次');
};

const throttleTest = throttle(test, 300);

// 300ms后
throttleTest(); // 执行一次；
throttleTest();
// 300ms后
throttleTest(); // 执行一次；
throttleTest();
// 300ms后
throttleTest(); // 执行一次；
```
