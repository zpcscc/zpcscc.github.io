## 描述

版本号排序

## 参数

| 参数名 | 类型                   | 描述                 |
| ------ | ---------------------- | -------------------- |
| data   | `Array.&lt;string&gt;` | 需要排序的版本号数组 |

## 返回

`Array.&lt;string&gt;` - 从小到大排序过后的数组

## 示例 _(ts类型)_

```typescript
sortVersions(data:string[])
```

## 示例 _(demo)_

