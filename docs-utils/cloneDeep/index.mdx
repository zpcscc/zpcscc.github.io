---
title: "cloneDeep"
---

## 描述

将指定数据进行深拷贝，若无法拷贝则返回原数据

## 参数

| 参数名 | 类型             | 描述                |
| ------ | ---------------- | ------------------- |
| data   | `any` | 待拷贝的数据 |

## 返回

`string` - 深拷贝后的数据

## 示例 _(ts类型)_

```typescript
cloneDeep(data:any, opt?:number)
```

## 示例 _(demo)_

```typescript
import { cloneDeep } from '@site/src/utils';

console.log(cloneDeep('Name')); // Name
console.log(cloneDeep({ name: '张三' })); // {name:'张三'}
```
