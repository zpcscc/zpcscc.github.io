---
title: 'debounce'
---

## 描述

防抖函数

## 参数

| 参数名 | 类型       | 描述           |
| ------ | ---------- | -------------- |
| func   | `function` | 需要防抖的函数 |
| wait   | `number`   | 防抖等待的时间 |

## 返回

`function` - 返回防抖后的函数

## 示例 _(ts类型)_

```typescript
debounce(func: AnyFunction, wait: number): AnyFunction
```

## 示例 _(demo)_

```typescript
import { debounce } from '@site/src/utils';

const test = () => {
  console.log('执行一次');
};

const debounceTest = debounce(test, 300);

debounceTest();
debounceTest();
debounceTest(); // 执行一次；
```
