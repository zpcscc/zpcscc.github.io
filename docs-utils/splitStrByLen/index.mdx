title: "splitStrByLen"
---

## 描述

按指定长度拆分字符串

## 参数

| 参数名 | 类型                | 描述                              |
| ------ | ------------------- | --------------------------------- |
| value  | `string` | 待分割的字符串             |
| len    | `number` | 分割的数组每项的字符串长度 |

## 返回

`Array.&lt;string&gt;` - 分割后的数组

## 示例 _(ts类型)_

```typescript
splitStrByLen(value:string, len?:number)
```

## 示例 _(demo)_

```typescript
import { splitStrByLen } from '@site/src/utils';

console.log(splitStrByLen('张三张三张三', 2)); // ['张三','张三','张三']
console.log(splitStrByLen('123456789', 3)); // ['123','456','789']
console.log(splitStrByLen('1234567890', 4)); // ['1234','5678','90']
```
