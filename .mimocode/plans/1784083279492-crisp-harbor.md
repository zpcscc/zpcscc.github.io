# AI 聊天页面实现方案

## 概述

在 Docusaurus 静态站点中新增一个 ChatGPT 风格的 AI 聊天页面，使用小米 MiMo-v2.5 全模态模型，支持文本、图片、音频、视频输入。

## 技术方案

### 整体架构

```
用户浏览器
  └─ Docusaurus 静态站点
       └─ /ai 路由（新页面）
            ├─ 左侧边栏：对话历史列表
            └─ 右侧区域：聊天消息 + 输入框
                 ├─ 文本输入
                 ├─ 图片上传（拖拽/粘贴/选择）
                 ├─ 音频录制（麦克风）
                 └─ 视频上传
```

### API 调用

- **协议**: OpenAI 兼容 (`POST /v1/chat/completions`)
- **端点**: `https://api.xiaomimimo.com/v1/chat/completions`
- **模型**: `mimo-v2.5`（性价比最优）
- **流式响应**: SSE (Server-Sent Events) 实现打字机效果
- **开发阶段**: API Key 硬编码在配置文件中（后续替换为 serverless 代理）

### 多模态输入处理

| 输入类型 | 前端处理 | API 格式 |
|---------|---------|---------|
| 文本 | 直接发送 | `{ type: "text", text: "..." }` |
| 图片 | FileReader → base64 | `{ type: "image_url", image_url: { url: "data:image/...;base64,..." } }` |
| 音频 | MediaRecorder → Blob → base64 | `{ type: "input_audio", input_audio: { data: "...", format: "wav" } }` |
| 视频 | FileReader → base64 | `{ type: "video_url", video_url: { url: "data:video/...;base64,..." } }` |

## 核心组件设计

### 1. `types/index.ts` — 数据模型

```typescript
interface Message {
  id: string;
  role: 'user' | 'assistant' | 'system';
  content: string;                    // 文本内容
  attachments?: Attachment[];         // 多模态附件
  timestamp: number;
  status: 'sending' | 'streaming' | 'done' | 'error';
}

interface Attachment {
  id: string;
  type: 'image' | 'audio' | 'video';
  name: string;
  data: string;      // base64
  mimeType: string;
  size: number;
  previewUrl?: string; // blob URL for preview
}

interface Conversation {
  id: string;
  title: string;          // 首条消息前 20 字符
  messages: Message[];
  createdAt: number;
  updatedAt: number;
  model: string;          // 'mimo-v2.5' | 'mimo-v2.5-pro'
}
```

### 2. `services/mimoApi.ts` — API 调用

- 将 Message[] 转换为 OpenAI 格式的 messages 数组
- 多模态消息的 content 为数组格式（text + image_url / input_audio）
- 使用 `fetch` + `ReadableStream` 处理 SSE 流式响应
- 解析 `data: {...}` 格式的 SSE chunks，提取 delta.content

### 3. `hooks/useChat.ts` — 核心逻辑

- 管理当前对话的消息列表
- 调用 `mimoApi.ts` 发送消息
- 处理流式响应：逐步追加 assistant 消息内容
- 错误处理和重试

### 4. `hooks/useConversations.ts` — 对话管理

- 从 LocalStorage 加载对话列表
- 创建、重命名、删除对话
- 切换当前对话
- 自动保存（debounce）

### 5. `components/InputArea.tsx` — 输入组件

- 文本输入：`textarea` 自适应高度
- 图片上传：`<input type="file" accept="image/*">` + 拖拽 + 粘贴
- 视频上传：`<input type="file" accept="video/*">`
- 音频录制：`AudioRecorder` 组件（开始/停止/预览）
- 附件预览栏：显示已选择的附件缩略图 + 删除按钮
- 文件大小限制：图片 20MB，视频 100MB，音频 25MB

### 6. `components/MessageBubble.tsx` — 消息渲染

- 用户消息：右对齐，显示文本 + 附件缩略图
- AI 消息：左对齐，支持 Markdown 渲染（使用 Docusaurus 内置的 MDX 能力或引入 `react-markdown`）
- 代码块：语法高亮（复用项目已有的 PrismJS）
- 流式消息：显示光标闪烁动画

### 7. `components/Sidebar.tsx` — 侧边栏

- 对话列表：按更新时间倒序
- 新建对话按钮
- 每个对话：标题 + 时间 + 删除/重命名操作
- 当前对话高亮
- 折叠/展开（移动端）

## LocalStorage Schema

```typescript
// Key: 'ai-chat-conversations'
// Value: JSON string of ConversationMeta[] (不含完整消息)
interface ConversationMeta {
  id: string;
  title: string;
  createdAt: number;
  updatedAt: number;
  messageCount: number;
  model: string;
}

// Key: 'ai-chat-conversation-{id}'
// Value: JSON string of Conversation (含完整消息)
// 单个对话单独存储，避免 LocalStorage 5MB 限制
```

## Docusaurus 集成

### 路由

在 `src/pages/ai/index.tsx` 创建文件，Docusaurus 自动注册为 `/ai` 路由。

### 导航栏

在 `docusaurus.config.ts` 的 `navbar.items` 中添加：
```typescript
{ label: 'AI 助手', position: 'left', to: '/ai' }
```

### 主题集成

- 使用 UnoCSS 原子类 + Docusaurus CSS 变量实现暗色/亮色主题
- 复用项目已有的 UnoCSS shortcuts（`u-center` 等）
- 不使用 CSS 文件（遵循项目规则），全部用 UnoCSS

### SSR 处理

AI 聊天页面涉及浏览器 API（LocalStorage, MediaRecorder, fetch SSE），需要客户端渲染：
- 使用 Docusaurus 的 `BrowserOnly` 包裹
- 或在组件内使用 `useEffect` + 动态 import

## 已知限制与后续优化

### 当前限制
- **API Key 暴露**: 前端硬编码，仅限开发/演示
- **CORS**: MiMo API 可能不允许浏览器直接调用，需测试
- **文件大小**: LocalStorage 5MB 限制，大对话需分页或清理
- **无用户认证**: 所有数据存本地，清浏览器数据即丢失

### 后续优化方向
- 添加 Cloudflare Workers 作为 API 代理（隐藏 Key + 绕 CORS）
- 支持对话导出/导入（JSON 文件）
- 支持 Markdown 渲染（代码高亮、表格、列表）
- 支持对话搜索
- 支持系统 Prompt 自定义
- 支持模型切换（mimo-v2.5 / mimo-v2.5-pro）
- 语音合成回复（MiMo TTS）
